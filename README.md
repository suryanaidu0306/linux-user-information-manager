# Linux User Information Manager

## Description
A Bash script that displays useful information about Linux users.

## Features
- Current user
- User ID (UID)
- Group ID (GID)
- Home directory
- Logged-in users
- Last login history
- User groups

## Commands Used
- whoami
- id
- who
- last
- groups

## Run

```bash
chmod +x user_info_manager.sh
./user_info_manager.sh
```
